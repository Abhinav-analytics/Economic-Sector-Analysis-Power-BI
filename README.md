# Economic Sector Analysis of India and Global Economies using Power BI

## Project Overview
This project uses Microsoft Power BI to explore and compare economic indicators across countries, years, and economic sectors. The dashboard is intended to make sector-level economic data easier to explore through interactive visualizations.

## Project Objectives
- Explore economic indicators across countries and years.
- Compare sectors such as Agriculture and Manufacturing, along with other sectors included in the dataset.
- Examine GDP value, employment percentage, and growth rate.
- Present the data in an interactive Power BI report to support comparisons and trend analysis.

## Tools & Technologies
- Microsoft Power BI
- CSV dataset
- Data visualization and analysis

## Repository Contents
- `Economic Sector Analysis of India and Global Economies using Power BI.pbix` — Power BI report file.
- `Data_project---Economic Sector Analysis of India and Global Economies using Power BI - Copy(1).csv` — dataset used by the project.

## Dataset Description
The CSV dataset contains 15,000 rows and the following fields:
- `Country` — country name
- `Year` — year of the observation
- `Sector` — economic sector
- `GDP_Value_USD_Bn` — GDP value, represented in USD billions
- `Employment_%` — employment percentage
- `Growth_Rate_%` — growth rate percentage

The dataset may contain blank values. Review data types and missing values when refreshing or modifying the report.

## How to Open the Project
1. Download or clone this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. If Power BI asks for the data source, point it to the CSV file included in this repository.
4. Refresh the data if required, then explore the report pages, filters, and visuals.
